## 解压

标准 7z 格式，用 [7-Zip](https://www.7-zip.org/) / WinRAR / PeaZip，或命令行 `7z x 文件名.7z`。

**为什么能压到这么小？**
该文件每个样本只有 `+1.0` 和 `-1.0` 两种取值。IEEE 754 double 的 +1.0 是
`00 00 00 00 00 00 F0 3F`、−1.0 是 `00 00 00 00 00 00 F0 BF` —— 八个字节里只有最后一个在变。
LZMA 对这种超长游程的编码效率极高：8.69 GiB → 8 MB，**压缩比约 1110:1**
（信息熵约等于每样本 1 bit）。所以「体积 8.69 GiB」和「压缩包只有 8 MB」并不矛盾。
